## 来源怎么接

搜索接口许可和源站内容许可分开核对。能打开页面、robots 未禁止，不等于允许长期保存或对外分发。

| 来源 | 当前状态 | 下一步 |
| --- | --- | --- |
| Tavily 搜索与提取 | 条款允许客户应用集成，但含内部业务用途、第三方责任及输入使用条款 | 单人试验只发送公开研究词；向小分队提供服务前确认适用套餐、片段保存和删除要求 |
| Shopify 社区 | 本次条款入口返回 403；上一轮可读性不代表授权 | 核对社区内容条款，确认自动读取、模型处理、必要摘录保存及删除条件；未明确前不列入自动正文读取名单 |
| Shopify 应用评价 | robots 可读，未据此确认内容使用权 | 单独核对评价条款，不能沿用社区结论 |
| Reddit / Upwork | 既有记录显示商业或自动化用途涉及平台批准；本轮未复核账户授权 | 首版不做自动正文适配器，后续有适用权限再接 |

[Tavily 条款](https://www.tavily.com/terms)第 2、3、6、9、10 节涉及上述边界；不能因使用其 Extract 服务就跳过源站权限。未核实的保存许可保持未知。来源获取失败与权限未明确分别记录；仅在允许保存搜索摘要时降级为 `snippet_only`。

向供应商或源站核对时，具体说明：低频自动读取公开讨论/评价，将必要片段发送至文本 API 做需求分析，保存链接、日期和摘录；先个人内部使用，之后可能向付费用户展示。确认两个阶段是否允许、保存期限、署名与删除要求。当前没有代用户联系任何平台。
