## 学习目标

- 用试跑记录判断任务是否稳定
- 一次只修正少量问题
- 决定继续自动化、保持半自动或停止投入

## 1. 一次成功不代表稳定

使用相似任务连续试跑，才能看出问题来自：

- 输入材料不完整
- 任务卡不清楚
- 权限或工具不合适
- 验收方式缺失
- 任务本身不值得自动化

## 2. 每次只记录四项

| 记录项 | 内容 |
| --- | --- |
| 输入 | 本次使用了哪些材料 |
| 动作 | AI 实际做了什么 |
| 接管点 | 人在哪一步介入，为什么 |
| 结果 | 是否可用，错误在哪里 |

发现问题后，一次只改一两个变量，避免无法判断是哪项修改有效。

## 3. 做出下一步决定

- **保存模板：** 结果稳定，人工只做快速核验
- **保持半自动：** 仍需要较多判断，但能节省准备时间
- **停止投入：** 维护成本高于节省的时间，或风险无法控制

先把协作做稳，再增加工具、长期记忆、定时触发和自动执行。

## 本课练习

用任务卡完成一次低风险试跑，填完四项记录，并写下下一步决定。

完成标准：不以“AI 成功输出了一次”为结论，而是有记录、有问题、有明确取舍。
