## 学习目标

- 把 `Qoder CN / 通义灵码 / Qoder / TRAE / CodeBuddy` 放进同一张对比表
- 理解阿里系入口为什么要分 `Qoder CN / 通义灵码` 和 `Qoder` 两类看
- 带走一套更实在的国内 IDE Agent 选型建议

## 学完能做什么

- 能用同一个真实仓库任务比较国内 IDE Agent，而不是看功能表排名
- 能把工具体验、团队治理、采购/合规和模型生态一起纳入试点
- 能设计一个低风险、可复盘的 2 周试点任务

## 适合谁

- 想在中国环境里落地 AI 编程的个人开发者和团队负责人
- 想知道国内工具之间到底怎么分，不想只看品牌名的人

## 核心知识

### 1. 先看清：国内主流产品都在走 IDE Agent 路线

现在国内主流产品比的已经不是“有没有补全”，而是：

- 能不能读仓库、跨文件改动、维护规则和上下文
- 能不能把 AI 变成 IDE 里的主工作台
- 能不能接企业知识、权限、审计和云生态

所以真正该比较的是：`Agent 深度`、`产品成熟度`、`团队治理`、`生态协同`。

### 2. 阿里系入口要拆开看：Qoder CN / 通义灵码和 Qoder

**Qoder CN / 通义灵码**

- 更像普及型入口
- 中文、采购、阿里云接入阻力更低
- 适合想先铺开使用的团队

**Qoder**

- 更像深度 Agentic IDE
- 强调 `Quest`、`Repo Wiki`、`Rules`、`Hooks`
- 更适合已经习惯 Cursor 这类工作流的开发者

最简单的理解是：

- `Qoder CN / 通义灵码` 偏“低摩擦推广”和国内企业落地
- `Qoder` 偏“更深的 Agent 工作流”

名称、入口和迁移关系以阿里官方当前页面为准；课程里把它们作为两类产品路线来理解，不把名称当成固定不变的组织结构。

### 3. 其他两条主线：TRAE 和 CodeBuddy

**TRAE**

- 更像一体化 AI IDE
- Builder、Agent、MCP、规则这些能力更容易在一个工作台里串起来
- 适合把 AI IDE 当主入口的个人和小团队

**CodeBuddy**

- 更偏团队流程和组织治理
- IDE、CLI、规则、MCP、Memory、Skills、Agent 等链路更完整
- 适合后面要接团队协作、规则、交付流程的团队

### 4. 当前实际体验：用同一个任务试，不做静态排名

官方能力表只能说明“能做什么”，不能说明“在你的仓库里稳不稳”。建议用同一个真实任务试四件事：

- 是否能准确理解仓库结构和项目规则
- 跨文件改动后你需要手动打断多少次
- 规则、MCP、知识库和团队治理是否能接进现有流程
- 价格、账号、采购、网络和合规是否适合你的组织

这意味着如果你只看功能表，很容易得出错结论。  
真正影响日常使用的，往往是稳定性、团队接入成本和是否敢拿来做真实任务。

### 5. 一张够用的选择表

| 工具 | 更像什么 | 当前更适合谁 | 现在最该注意什么 |
| --- | --- | --- | --- |
| Qoder CN / 通义灵码 | 普及型 IDE Agent | 想低摩擦推广的团队 | 容易被只用成高级补全 |
| Qoder | 深度 Agentic IDE | 熟悉 Cursor 路线的开发者 | 更适合专项试点，不一定适合立刻全员推 |
| TRAE | 一体化 AI IDE | 个人开发者、小团队 | 重点验证真实仓库里的跨文件质量和规则执行 |
| CodeBuddy | 团队流程型 AI 工作台 | 要接组织治理的团队 | 重点验证 IDE/CLI/团队流程能否接进现有规范 |

### 6. 直接给结论

如果你是个人开发者：

- 先试一个你最容易连续使用 2 周的 IDE Agent
- 如果要低门槛中文体验，看 `Qoder CN / 通义灵码`
- 如果要深工作流，看 `Qoder`

如果你是小团队负责人：

- 想快速推开：先试 `Qoder CN / 通义灵码`
- 想让核心开发者深度用 Agent：补试 `Qoder`
- 想兼顾日常 IDE 体验：把 `TRAE` 放进同题试点

如果你是企业技术管理者：

- 先看治理和组织接入，再看单次效果
- `CodeBuddy` 这类团队流程工具适合小范围试点，不建议只看能力表就大规模铺开

## Demo

同一个需求，四条路线的重点不同：

- `Qoder CN / 通义灵码`：先解决低摩擦接入和团队普及
- `Qoder`：先解决仓库级理解和深度 Agent 执行
- `TRAE`：先解决主工作台体验和整体成熟度
- `CodeBuddy`：先解决流程、协作和治理接入

## 常见误区

1. **把 Qoder CN / 通义灵码和 Qoder 当成完全相同的入口**
2. **只看能力列表，不做真实任务试点**
3. **只看个人体验，不看后续团队推广**
